# AquaBlade Water Jet Services Website

A premium website for AquaBlade water jet cutting services featuring a dynamic pricing calculator.

## Features

- 🎨 **Modern Design** - Icy blue/gray/white color palette with glassmorphism effects
- 📁 **DWG/DXF File Upload** - Upload CAD files for automatic path length extraction
- 🧮 **Dynamic Pricing Calculator** - Real-time cost estimation based on material and thickness
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop
- ✨ **Smooth Animations** - Micro-interactions and scroll animations

## Materials Supported

- Stone & Granite
- Glass & Crystal
- Steel & Iron
- Stainless Steel
- Rubber & Foam
- Carbon Fiber
- Aluminum
- Titanium
- Copper & Brass
- Ceramic & Tile

## Deployment

This is a static website that can be deployed to any hosting platform:

### Netlify (Recommended)
1. Push to GitHub
2. Connect repository to Netlify
3. Deploy automatically

### Vercel
1. Push to GitHub
2. Import project in Vercel
3. Deploy automatically

### GitHub Pages
1. Push to GitHub
2. Enable GitHub Pages in repository settings
3. Set source to main branch

## Local Development

```bash
# Start local server
python3 -m http.server 8080

# Open in browser
open http://localhost:8080
```
